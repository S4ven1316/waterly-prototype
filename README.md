# Human Computer Interaction (HCI) Project

This project was developed as part of the **Human Computer Interaction (HCI)** course. The purpose of this project is to design and implement a user-friendly, responsive, and interactive web interface by applying HCI principles and usability concepts.

## 📌 Project Overview

The application focuses on creating an intuitive user experience through a clean interface, responsive design, and interactive components.

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Tailwind CSS
